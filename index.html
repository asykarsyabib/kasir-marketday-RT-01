Setiap pesanan baru akan otomatis tersinkronisasi ke Google Spreadsheet Anda

Cara Penghubungan (Cukup 1 Kali Setup):
  1. Buka Google Sheets Anda, pilih menu Ekstensi (Extensions) > Apps Script.
  2. Hapus semua kode bawaan, lalu salin & tempel skrip di bawah ini:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.id, data.timestamp, data.customerName, data.items, data.total, data.cashPaid, data.change, data.status]);
  return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
}
  1. Klik tombol Deploy (Terapkan) > Deployment Baru.
  2. Pilih jenis Web App, ubah akses Who has access menjadi Anyone (Siapa Saja).
  3. Klik Deploy, lalu salin Web App URL dan tempel di kotak di atas.
